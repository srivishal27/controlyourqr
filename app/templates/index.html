Why this exists

Most "free online QR generators" are not free, and many are not even QR generators. They are redirect services with a QR code drawn on top. Here is the pattern, and how this site refuses it.

The usual trick

  • The code points at them, not at you. Many sites hand you a dynamic QR that encodes their-domain.com/abc123. Every single scan travels through their server before reaching your link.
  • It expires unless you pay. The trial ends, the redirect is switched off, and the code you printed on 5,000 flyers, a banner or a product label goes dead.
  • The destination can be changed later. Whoever controls that redirect controls where your code sends people — including after your posters are on the wall.
  • Every scan is logged. IP address, rough location, device, time and referrer are collected from people who only wanted to scan a menu.
  • Your input was uploaded. The Wi-Fi password, private link or contact card you typed was sent to a server you have never audited and cannot inspect.
  • Then come the walls. Sign-up prompts, watermarks, "high resolution is a Pro feature", an email address harvested for marketing.

What this site does

  • Static codes only. Your destination is encoded directly into the pattern. There is no middleman domain and no hop to anyone's server.
  • It cannot expire. A static QR code keeps working even if this website disappears tomorrow. Nothing to renew, nothing to switch off.
  • Nobody can repoint it. Not us, not a future owner of this domain. The link lives in the ink, not in a database.
  • No scan tracking exists. There is no analytics on the scan path, because there is no scan path. We never learn that your code was used.
  • Nothing you type leaves the tab. The encoder is JavaScript running on your machine. The server sends files out; it takes nothing in.
  • Free, unlimited, unbranded. No account, no watermark, no resolution limit, no "Pro". Print-ready PNG and true vector SVG for everyone.

The honest caveat: dynamic QR codes are a legitimate product when you genuinely need editable destinations and scan analytics, and some vendors are upfront about it. The problem is the sites that sell you one while calling it a free QR code — and the ones that quietly read what you typed on the way. If you need a static code that simply works forever, you should never have to hand your data to anyone.

Don't trust us. Verify.

A privacy claim you cannot check is just marketing. Every one of these takes under a minute.

  1. Pull the plug

    Load this page, then turn off Wi-Fi and mobile data. Generate a code, change the colours, download the PNG and the SVG. It all still works, because none of it needed a network.

  2. Watch the network tab

    Open DevTools → Network, then type into any field. You will see zero requests. Not a beacon, not a pixel, not an analytics ping.

  3. Read the policy the browser enforces

    Check the response headers for Content-Security-Policy. It contains connect-src 'none' — an instruction to your browser to block every outbound request this page could attempt. Even if our code tried to phone home, your browser would stop it.

  4. Read the source

    The whole project is public and MIT licensed. The QR encoder is the open-source node-qrcode library, built from source and served from this domain — there is no third-party CDN, no font service and no tag manager anywhere on the site.

About

Designed and developed by Vishal Srivastava, security researcher and PhD Scholar at IIT Kanpur, who built this secure QR code generator after watching people paste passwords, private links and personal details into websites that had no reason to receive them.

The design goal was narrow and deliberate: produce a correct, static, print-quality QR code without the site ever learning what it contains. That constraint is why there is no account system, no history, no cloud sync and no API — each of those would require the data to leave your device.

Found a flaw? Reports are genuinely welcome — see the security page or security.txt.
